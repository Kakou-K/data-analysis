# SQL Learning & Practice

A collection of hands-on **Microsoft SQL Server (T-SQL)** exercises documenting my progress in SQL and data analysis.

## About

This repository is my SQL practice workspace. It contains exercises ranging from basic queries to more advanced techniques for retrieving, combining, summarizing, and transforming data.

The exercises use example tables such as `employees`, `departments`, and `projects`. Some questions include more than one solution to compare different SQL approaches.

## Topics covered

- **SQL fundamentals:** `SELECT`, `DISTINCT`, filtering, sorting, and operators
- **Joins:** combining data across related tables
- **Aggregations:** `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `GROUP BY`, and `HAVING`
- **Conditional logic:** `CASE WHEN`
- **Subqueries and CTEs:** breaking down more complex queries
- **Views and set operations:** `CREATE VIEW` and `UNION`
- **Data preparation:** cleaning and transforming values
